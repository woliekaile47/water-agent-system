# Phase 2D-C23：5 cm 欠分割改进（seed312 开发实验）

## 实验目的

本阶段只改进 5 cm 浅水的自动提示覆盖与 SAM 2 视频传播，不训练或更换 SAM 2，不修改水位反演、DEM 重建和 quality gate 阈值。seed312 是开发数据，不作为 held-out 成绩；后续必须用冻结规则在全新 seed313 上验证。

## 数据与隔离协议

- 场景：`sim_water_5cm_001`。
- 雨强：light、moderate、heavy。
- 动态 seed：312。
- 每组 60 秒、20 FPS、1201 张源帧；固定提取 41 帧传播窗口。
- 三种雨强使用同一套参数，禁止逐雨强调参。
- prediction 在读取 GT 前完成并记录 SHA-256；GT 只由独立 evaluation 脚本读取。
- 小雨 prediction 被拒绝后没有运行 SAM 2，也没有人工补点。
- 所有结果均为非 authoritative，`eligible_for_downstream=false`，未接入 S5-S8。

## C22 基线定位

小雨没有合格融合窗口，安全拒绝。中雨和大雨能够生成 prompt 并完成传播。大雨具有典型欠分割特征：precision 较高而 recall 很低，说明模型主要漏掉水域边缘，而不是大面积误报。

## 改进方法

### 1. 小雨跨窗口佐证

`unknown_fraction_high` 不再直接使窗口失去融合资格，但该窗口仍保持 `partial`，不能单独进入 SAM 2。它必须同时满足既有的空间聚类、至少 3 个重复支持窗口、至少 15 秒跨度、组件面积和无歧义要求。quality gate 本身及其阈值没有改变。

### 2. Recurrent-support prompt envelope

正点仍只从原来的高置信核心中选择，以下安全要求保持不变：

- 正点概率不低于 0.50；
- 正点跨窗口支持比例不低于 2/3；
- 正点距离边界至少 3 px；
- 正点间距至少 10 px；
- 最少 3 个安全正点。

新增的 prompt envelope 只吸收与高置信核心连通、概率不低于 0.20、跨窗口支持比例不低于 1/3 的像素。它仅用于扩大 box 和阻止负点落入重复出现的浅水候选区，不直接成为预测水 mask。若 envelope 超过核心面积 6 倍则回退到原核心；既有最大 box 面积、边缘接触、组件歧义和非有限值检查继续生效。

## seed312 结果

小雨从 0 个合格窗口改善到 7 个可参与窗口，但最终只有 2 个窗口支持同一重复核心，仍低于最低 3 个，因此保持 reject，未运行 SAM 2。这是数据证据不足的安全失败，不用人工提示或降低阈值绕过。

中雨与大雨的正点坐标保持不变。中雨 envelope 从 737 px 扩展至 1203 px；大雨从 282 px 扩展至 1135 px。大雨 box 从 47×41 扩展至 74×58，负点移到 envelope 外。

## Quality gate 结论

候选中雨 9/41 帧 pass，大雨 4/41 帧 pass；其余帧唯一拒绝原因为 `camera_reprojection_iou_below_threshold`。没有修改该阈值。候选重投影 IoU 中位数为：

- moderate：0.8837；
- heavy：0.8611。

因此 C23 解决了欠分割和传播崩缩，但尚未达到“整段序列 quality gate 稳定通过”。当前结果不能进入正式 S5-S8。

## 当前结论与下一步

本阶段属于“欠分割改进有效、全链路门控尚未完成”。C23 保留为独立候选，不覆盖 C22。完成 seed306 非退化回归和全量测试后，冻结参数，用 seed313 的 light/moderate/heavy 各运行一次正式 held-out。seed313 若失败必须保留，不得根据其 GT 再调参数。
